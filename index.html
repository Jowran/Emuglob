Retrouver mes sauvegardes

Les fichiers trouvés sont copiés dans les sauvegardes d'Emuglob : l'original n'est ni déplacé ni modifié, et une sauvegarde déjà présente dans Emuglob part d'abord dans l'historique du jeu. Au prochain lancement, Emuglob la donne à l'émulateur si elle est plus récente que la sienne.
Les cartes mémoire communes à tous les jeux (PCSX2, Dolphin) restent dans leur émulateur.

Core manquant

Les cores sont téléchargés depuis le site officiel de libretro (buildbot.libretro.com, Windows 64 bits) et placés dans le dossier Cores de RALibretro. Ce sont des logiciels libres, distincts d'Emuglob.

Cores RALibretro

Téléchargés depuis le site officiel de libretro (buildbot.libretro.com, Windows 64 bits) dans le dossier Cores de RALibretro. « Mettre à jour » reprend la dernière version. Logiciels libres, distincts d'Emuglob.

Mettre à jour Emuglob

Recherche de mises à jour…


  

  
Sinon, à la main : télécharge le nouveau fichier app.asar, puis choisis-le ici : Emuglob se ferme, le remplace et se relance tout seul. L'ancienne version est gardée pour pouvoir revenir en arrière.

  

  




  
Choisir une version

  

  
Installe n'importe quelle version publiée, même plus ancienne. Emuglob se ferme, la remplace et se relance ; la version actuelle est gardée pour revenir en arrière. Une version antérieure à 1.3.0 n'a pas ce choix : pour revenir, accepte la mise à jour proposée au lancement.

  

  




  
Supprimer la ROM ?

  

  
Ces fichiers seront supprimés définitivement du PC, sans passer par la corbeille. Impossible d'annuler. Tes sauvegardes de jeu sont gardées.
